## SOBRE O PROJETO

Este é um **Sistema Especialista** desenvolvido como projeto prático para a disciplina de **Inteligência Artificial**. O sistema simula o raciocínio e a tomada de decisão de um profissional de Educação Física (Personal Trainer), recomendando rotinas de treinos personalizadas e gerando justificativas fisiológicas detalhadas com base nas características individuais de cada usuário.

O motor do sistema utiliza uma abordagem de **Inteligência Artificial Simbólica baseada em Regras de Produção** ($SE... ENTÃO...$) utilizando a estratégia de **Encadeamento para Frente (Forward Chaining)**.
